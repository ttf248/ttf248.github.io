GPT-6 降价以后，Claude 还值高价吗？

OpenAI把Sol和Luna推到更低价位，Anthropic也在降低Opus和Fable的实际任务成本

2026年09月23日 · 阅读时长: 11 分钟 · tianlong.xiang · v8.8.0
分类
  • AI 随笔杂谈
AI 写作

9 月 22 日，OpenAI 发布 GPT-6 Sol 和 Luna，把两款模型的 API 单价降到 GPT-5.6 促销价的一半。同一天，Anthropic 发布 Opus 5.5：它的 token 标价比 Opus 5 低两成，缓存读取也便宜了六成。看起来像是 OpenAI 开始打性价比、Claude 继续卖高端；细看价格和定位，这种分法已经不够准确。

GPT-6 的价格梯子变长了

GPT-5.6 原来有 Sol、Terra、Luna 三档：Sol 是旗舰，Terra 在能力和成本之间取平衡，Luna 面向高吞吐、低成本任务。到 GPT-6，OpenAI 又把 Astra 放在最上面，当前产品线是 Astra、Sol、Luna，没有发布 GPT-6 Terra。价格上，GPT-6 Sol 正好落在 GPT-5.6 Terra 原价附近；名称沿用的 Sol，则从上一代旗舰变成了 GPT-6 的中间档。

下表按 API 标准文本价格比较，每百万 token 计价，单位为美元。GPT-5.6 的价格已计入 OpenAI 当下公布的折扣；Sol 的促销价至少维持到 2026 年 11 月 21 日。

系列 模型 输入 输出 官方定位
GPT-5.6 Sol $4 $20 旗舰；当前为促销价
GPT-5.6 Terra $2 $12 能力与成本平衡
GPT-5.6 Luna $0.20 $1.20 经济型、高吞吐
GPT-6 Astra $10 $50 当前最强，面向复杂推理与编码
GPT-6 Sol $2 $10 复杂编码与 Agent 工作流
GPT-6 Luna $0.10 $0.50 聚焦任务与大批量调用
Claude Fable 5.1 $10 $50 最强通用型号，长时间、多阶段任务
Claude Opus 5.5 $4 $20 复杂编码、知识工作与多工具 Agent
Claude Sonnet 5 $2 $10 中档通用模型
Claude Haiku 4.5 $1 $5 更轻、更快的日常任务

截至 9 月 23 日，GPT-6 Astra 已在 ChatGPT 付费套餐和 API 提供；刚发布的 Sol、Luna 则在 API、ChatGPT Work 和 Codex 陆续上线，暂时还不能在普通 Chat 对话里选择。Free 和 Go 用户可在桌面应用里使用 Luna。模型已经发布，不代表每个账户当天都能看到入口。

比较表看起来很直观，但它只回答“一个 token 卖多少钱”。GPT-6 Astra 与 Fable 5.1 的基础标价同为 $10/$50；GPT-6 Sol 与 Claude Sonnet 5 同为 $2/$10。相同价格不代表相同能力，低单价也不自动等于完成任务更便宜。

OpenAI 的 GPT-6 标准价适用于输入不超过 272K token 的常见请求；更长上下文有更高费率，缓存读写也另计。Anthropic 的 Fable 5.1 缓存读取降到了每百万 token $0.25，Opus 5.5 是 $0.20。Anthropic 还说明，4.7 及之后的模型换了 tokenizer，同一段文本平均可能产生约 30% 更多 token。因此，跨厂商只比较表格里的裸单价，不能直接推算同一份材料的账单。

Luna 已经能和国产模型比价，但不是处处最低

按 9 月 23 日人民币汇率中间价，1 美元约合 6.7468 元。GPT-6 Luna 的输入、输出标价折算后约为 每百万 token ¥0.67 和 ¥3.37。以阿里云 Model Studio 的中国大陆 API 价作参照：

模型 输入 输出 口径
GPT-6 Luna ¥0.67 ¥3.37 按当日人民币中间价折算
Qwen3.7 Plus ¥2 ¥8 256K 内标价；页面另标有 20% 限时优惠
Qwen3.7 Flash ¥0.20 ¥0.80 输入不超过 32K；更长上下文价格上调

**Luna 确实低于部分国产通用模型的标价，但国产 Flash 档还能更便宜。**所以“比很多国产模型便宜”可以成立，“比国产模型都便宜”则不成立。这里比较的仍只是 API 标价，模型能力、促销折扣、批量调用和缓存机制都不同，不能把价格排名当成质量排名。

哪些任务该交给哪一档

官方给出的用途不是纯粹的能力榜单，而是工作量和成本之间的分配。OpenAI 的 API 指南建议，复杂推理和编码先用 Astra，需要平衡成本时选 Sol，成本敏感、调用量大的任务用 Luna。Anthropic 则把 Fable 5.1 放在长时间、异步、少人盯守的项目上；Opus 5.5 面向严肃编码、知识工作和长流程 Agent。

模型 更适合的工作 选择时留意
GPT-6 Luna 分类、抽取、格式整理、摘要、批量初筛、简单代码维护 单价最低；复杂任务可能要更多轮次或人工返工
GPT-6 Sol 日常编程、跨工具操作、需要规划和检查的 Agent 工作 比 Astra 便宜很多，适合作为常用工作档
GPT-6 Astra 新问题、复杂代码库、高代价的多步工作 标价最高；先确认它能否显著减少失败和返工
Claude Opus 5.5 复杂编码、长上下文分析、金融和文档工作、多工具协作 比 Fable 便宜；新版本刚发布，最好用自己的任务检验
Claude Fable 5.1 多日代码项目、深度研究、复杂企业流程、长时间无人值守的工作 单价仍高，适合失败代价大、能省下大量人工盯守的任务

Anthropic 的用户模型也不只有 Fable 和 Opus：当前价目表还列有 Sonnet 5 和 Haiku 4.5。两家公司都在把能力拆成多个价位，而不是只保留一个最强、最贵的模型。

网上讨论先谈额度，再谈能力

GPT-6 Sol 和 Luna 才发布一天，讨论还不能算稳定评价。Codex 社区里对降价普遍敏感：有人认为同样预算可以多跑任务，足以抵消能力提升不明显；也有人觉得实际编码质量和上一代差不多，或在刚开放时遇到模型不可用、调用报错。两种反馈同时存在，说明多数人在评估的首先是“能多用多少”，不是“它是不是绝对更聪明”。

Fable 的用户讨论则经常把能力和用量限额放在一起：有人认可它处理长任务的效果，但表示高强度使用很快就会消耗订阅额度，于是把 Fable 留给架构、审查或 Opus 卡住的部分。Opus 5.5 是同一天发布的新型号，社交平台上已有用户称赞，也有人提醒发布当天的厂商榜单和少量实测都不足以定论。这些是论坛里的早期体验，不是随机抽样的用户调查，更不能代替同一任务上的实测。

这里还要把 API 价格和订阅价格分开。上面的表是按 token 付费的 API 价；ChatGPT 与 Claude 的订阅则按套餐提供额度或使用上限。API 单价降一半，不一定意味着订阅用户的调用次数也翻倍；一个长上下文、反复工具调用的 Agent，也可能比短问答更快耗尽额度。

两家公司开始竞争同一笔成本

Anthropic 的品牌印象仍然是：Fable 处于高价、高能力一端。它的基础价没有随 Fable 5.1 下调，仍是 $10/$50；但缓存读取比 Fable 5 便宜 75%。Anthropic 根据真实工作负载估算，普通使用的总成本约降 25%，复杂编码和高 Agent 调用任务最多可降约 45%。Opus 5.5 也降到 $4/$20，官方估算典型任务的运行成本比 Opus 5 低约 40%。这不是“高价不变”，而是保留顶层标价，同时降低长任务的实际账单。

OpenAI 的变化更容易从价格表看出来：GPT-6 Astra 仍站在 $10/$50 的高端，Sol 走到 $2/$10，Luna 则下探到 $0.10/$0.50。它不是放弃高价旗舰，而是把更便宜的模型推到更显眼的位置，希望低成本模型也能承接更多日常工作。GPT-6 Sol 和 Luna 是基于 Astra 的技术进展做出的更快、更便宜版本，官方强调的是能力、效率和使用量一起改善。

**两家的策略没有简单地分成“Claude 贵、OpenAI 便宜”；更明显的变化是都在按任务切分模型，并把竞争指标从 token 单价推向“每项成功工作要花多少钱”。**区别在于，OpenAI 这次把低价梯度摆到了台前；Anthropic 仍用 Fable 维持最高能力的定位，同时靠更便宜的缓存和 Opus 5.5 降低完成任务的成本。Luna 的价格确实进入了国产模型的竞争区间，但最后值不值，得看它能否一次做对，而不是账单上每个 token 有多便宜。
