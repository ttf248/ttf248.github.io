一、全球旗舰主线：H100 起跑，H200 补显存，Blackwell 卖整柜

型号 发布时间 架构 显存与带宽 互连 核心定位
A100 80GB 2020（基线） Ampere 80GB HBM2e（2.039 TB/s） NVLink 600 GB/s ChatGPT 前的大模型基准卡
H100 SXM 2022-03 Hopper 80GB HBM3（3.35 TB/s） NVLink 900 GB/s 拉开生成式 AI 训练大幕，BF16 峰值跃升
H200 SXM 2023-11 Hopper 刷新 141GB HBM3e（4.8 TB/s） NVLink 900 GB/s 显存容量 +76%、带宽 +43%，专补长上下文与推理瓶颈
B200 SXM 2024-03 Blackwell 180GB HBM3e（8 TB/s） NVLink 1.8 TB/s 转向整柜平台交付（DGX B200 挂牌价较 DGX H100 高约 40%～50%）
B300 / Ultra 2025-03 Blackwell Ultra 288GB HBM3e（8 TB/s） Rack-scale 互连 面向长思维链 Reasoning 与大规模推理

最值得记住的不是单卡峰值 TFLOPS，而是英伟达卖的东西变了：H100 时代还在比“单卡多猛”；H200 开始显存带宽成核心瓶颈；到 Blackwell 和 Vera Rubin，英伟达卖的是整套液冷机架、互连网络和软件栈，比的是“给定电力额度下能吐出多少 Tokens”（上游 CoWoS 与 HBM 物理瓶颈详见AI 算力与半导体产业链：谁在收租，谁在扛周期）。

二、中国特供线：目标函数从来不是“性能最强”，而是“合规可卖”

中国特供版（A800、H800、H20）绝对不能和全球旗舰线混成一条代际曲线：

  • A800（2022-11）/ H800（2023-03）：核心削减点在卡间互连带宽——单卡算力和本地 HBM 仍接近母体，但压低了大规模集群横向扩展效率。
  • H20（2024-02 预售）：面对更严规则，连核心计算能力也大幅压低，保留 96GB HBM3 与约 4.0 TB/s 带宽（公开渠道价约 1.2～1.5 万美元/卡，八卡整机约 140 万元人民币）。它不是 H800 的自然升级，而是为了在合规红线内保住推理可用性与 CUDA 生态的折中产物。

因此，全球旗舰平台一路涨价，而中国特供线反而可能出现“越晚出越便宜”，因为两者的目标函数根本不同。

三、Vera Rubin 的“十倍每兆瓦 Tokens”，会把 AI 价格打下来吗？

按英伟达针对 DeepSeek-R1 推理公布的机架级基准，Vera Rubin NVL72 的每兆瓦 Tokens 吞吐量达到 GB200 NVL72 的 10 倍。在电力接入、液冷和机房配额卡脖子的时代，这确实让数据中心扩容不必每次都先等变电站审批。

但电费只是服务商总成本（TCO）里的一行。把单位 Token 服务成本压成一条核心关系：

$$ \text{单位 Token 成本} \approx \frac{\text{硬件折旧} + \text{电力} + \text{机房网络} + \text{运维}}{\text{实际售出的 Tokens}} $$

从公式就能看清，能效十倍不会自动等于 API 降价九成：

  1. 硬件折旧同步抬升：Vera Rubin NVL72 整柜、Spectrum-6 网络与液冷基建的资本开支远高于旧机架，省下的电费很大一部分会被设备折旧吃掉。
  2. 分母是“实际售出”，不是“理论峰值”：机器闲置、低并发或调度排队时，再漂亮的每兆瓦指标也不会变成便宜账单。
  3. 效率先变体验，再变价格：服务商往往先把新增余量拿去拉长上下文、加长思考链、提升响应速度；而更便宜的推理又会激发十倍的 Agent 调用量，最终行业总电费和机房支出反而更大。

所以，Vera Rubin 的十倍能效是通往降价的门票，不是立刻生效的降价通知书。最终多少效率写进价目表、多少留在利润表，要看下游模型厂商的价格肉搏（详见大模型价格战进入深水区：GPT-6 降价后 Claude 还值高价吗）。
