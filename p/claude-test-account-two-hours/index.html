为了补齐模型测试我开了个活了两小时的账号

从前端任务对比到 Claude 订阅尝试，有些东西不必强求

2026年10月13日 · 阅读时长: 7 分钟 · tianlong.xiang · v8.11.1
分类
  • AI 随笔杂谈
AI 写作

中国护照，人脸验证，KYC 通过。那会儿挺美滋滋，觉得 Claude 的测试总算能接着做了。

两小时后，账号被封。

手续一道没少走，开心也是真的，只是短了点。

最近一直在折腾模型做前端任务的对比测试。OpenAI 家的模型测得差不多了，国产模型也做了几个。按我想覆盖的范围，主流模型里还缺 Anthropic 的 Claude 系列。做到这个份上，看着缺的那一块，总觉得差点意思。

其实不至于完全没测过。我已经通过小中转跑过测试，对它的能力层次有了大致感觉。停在那里，也能留下记录。但“有个印象”和“补完整”之间，总有一点让人心痒的距离。前面做得越多，剩下那点缺口反而越显眼。

于是，原本用来比较模型的时间，开始花在找模型的入口上。

从测试模型到计算额度

亚马逊、微软的渠道也看过。按我当时看到的报价，比官方 API 还贵，就没有觉得这条路多合适。GitHub Copilot 里有 Claude Opus，我先在那里跑了测试。

用下来的感受很直接：额度不耐用。

后来去看文档，才反应过来，这边给的也是按用量消耗的额度。GitHub 公告说明，月付 Pro、Pro+ 从 2026 年 6 月起改用按 token 计量的 AI 积分，既有年付套餐则有过渡安排。复杂任务、多轮对话、代理多次调用，都会继续消耗。付了订阅费，并不意味着后面就不用惦记用量了。计费说明

我当时记的是，花约 40 美元，拿到约 70 美元的用量。这里说的是我看到的套餐和自己的粗略换算，不是一笔能拿去调用任意官方 API 的现金余额，也不保证以后仍然一样。具体能跑多少任务，还得看选的模型和每次消耗。计费变更公告

这么看，它有点像在 OpenCode 这类工具里充值，再用带优惠的积分换模型用量。优惠是一回事，我这套任务能跑几轮，是另一回事。之前觉得不耐用，至少知道额度是怎样花掉的了。

可我没有就此收手，反而又惦记上官方订阅：渠道都看了一圈，既然还想补，干脆去官方试试。

身份验证过了，账号没留下

注册，付费，触发 KYC。拿中国护照加人脸验证，通过。

走到这里，很容易把前面的步骤连成一个顺理成章的结果：账号有了，钱付了，身份也验过了，接下来该轮到测试了。我当时就是这么想的。尤其验证通过，像是这趟折腾终于走到了头。

没想到两小时后，账号阵亡。

扫兴的不只是用不了，还有前面那点“这回成了”的高兴。验证通过这件事确实发生了，我从中读出的那份安心，却没有维持多久。

具体为什么被封，我不知道。手头没有足够信息，不能因为用了中国护照、随后被封，就把两件事直接连成原因。Anthropic 在 2025 年 9 月的官方公告中已明确，中国不在允许提供服务的地区范围内；这能说明服务的地区边界，但解释不了我这个账号究竟在哪一步出了问题。官方地区限制说明

科技存在国界。这句话落到自己身上，没有多复杂，就是模型在那里，我也想测，最后账号没能留下来。平时看发布、看效果，注意力全在它会做什么；真要拿来跑自己的任务，价格、渠道、额度和账号状态才一个接一个冒出来。

留个缺口

折腾到这里，我得回头看看，最初到底想做什么。

我想把模型测试记录做得更完善，倒也不是非要用 Claude。小中转已经让我有了初步认识，Copilot 也跑过测试，缺的是更完整的覆盖。为这点不完整继续找入口，当然还能找到再试一次的理由：前面已经花了这么多时间，差这一块，多可惜。

但前面花掉的时间，并不能替下一次尝试说明值得。

这回多出来的，主要是一段渠道和账号的使用经历。它可以记下来，却不会因为手续走得多，就自动补成模型能力的测试结果。把这两件事分清楚，那个空格也就没那么难看了。

能测到的继续记，测试不充分的写清楚。记录的用处，是让人知道我实际做到了哪一步，没必要看起来每一栏都满满当当。

有些东西不必强求。Claude 那一块先留着，这次不再为了补齐它开下一个账号了。

参考资料

  • 本文注册、付费、KYC 和封号经过来自个人经历；未取得具体封禁原因的证据。

  • GitHub Copilot 个人用户按用量计费说明：积分扣费机制及套餐额度，用于说明规则，具体账号结果仍以个人经历为限。

  • Anthropic 支持地区政策：服务支持范围，用于说明规则，具体账号结果仍以个人经历为限。

  • GitHub：按用量计费的过渡安排
