GPT-5.6 降价后，国内外大模型 API 到底差多少钱

用 Terra 的 $2 / $12 作基准，重排一张能复算的 API 价目表

OpenAI 这次确实降了价。7 月 30 日，GPT-5.6 Terra 的标准 API 价从 $2.50 / $15 降为 $2 / $12（输入 / 输出，每百万 token）；Luna 从 $1 / $6 降为 $0.20 / $1.20。前者降 20%，后者降 80%，Sol 不变。官方公告说得很直白。

不过，这不是 ChatGPT Plus、Pro 的月费打折。订阅价格和套餐配额预算没有变；改变的是在 Codex 与 ChatGPT Work 中使用 Terra、Luna 时的额度扣减，以及开发者 API 的按量单价。把订阅和 API 混在一起，往往是这条消息传播中第一个失真的地方。

Terra 是公开 API 模型，并非只有 ChatGPT 才能用的内部名称，所以可以成为一条干净的基准线。它现在每百万输入 token $2、每百万输出 token $12；下文所有百分比都以两者各用 1M token、合计 $14 的标准账单为 100。这个“1M 输入 + 1M 输出”很粗糙，但至少把输入和输出拆开又重新合上了，读者可以自行替换成自己的工作负载。

表内 428.6 的意思是合成标价为 Terra 的 428.6%，即比 Terra 高 328.6%，不是“贵了 428.6%”。Doubao 这一行是官网标出的“起”价，受地域、上下文与服务档位影响，因此它只能作为可见起步标价的排序位置，不能理解成无条件全国统一价。

还有四个同样重要的排除项：表中没有 Batch、Flex、Fast/Priority、缓存、工具调用、税费和企业协议价；均以未缓存的常规文本请求计。Terra 在输入超过 272K token 时，整单输入会按两倍、输出按 1.5 倍计价；Grok 4.5 在输入达到 200K 时也会切换到长上下文价格。GLM-5 与 ERNIE 5.0 的表价则限定在短上下文档。它们足以改变真实业务的排序。

OpenAI 为什么现在肯让价

官方给出的解释主要是工程效率：模型、承载推理的系统，以及连接工具和上下文的 Agent 层都做了优化。公告列出两项结果：生产内核优化使端到端服务成本下降 20%，实验令 token 生成效率提升超过 15%。这是厂商的披露，不是一份可供外部审计的成本表；它能说明“为什么可能有降价空间”，不能证明完整的利润率变化。

但价目结构本身也透露出策略。Sol 留在原价，Terra 与 Luna 向下调，意味着一条工作流可以把高难、低容错的环节留给高端档，把分类、抽取、后台批处理和定义清楚的子任务放进更便宜的档位。这是一种价格分层的观察，不是 OpenAI 对竞争动机的公开解释。

我认为，竞争也是合理但不能过度断言的背景。仅看这张表，Google、xAI、Mistral 以及多家中国厂商已经给出低于 Terra 的公开标价；Luna 的新标准账单甚至只有 $1.40。把高量任务的门槛压低，可能扩大 API 消耗，也可能让开发者先在低价层完成产品扩张，再为少数真正困难的步骤购买更强模型。究竟哪一种占主导，要看之后的用量和实际任务表现，不能从一次调价直接读出答案。

单价不是最终账单

真正的账单取决于完成一件事用了多少 token、有没有重试、缓存是否命中、延迟会不会逼出人工接管，以及模型在你的语言和工具链里是否稳定。一个单价更高的模型，若能少输出一半、少返工一次，完全可能更省钱。

选型时不妨拿十到二十个真实任务做一次小测评：先看成功率、延迟和人工返工；再记录输入、输出、推理 token、缓存命中与总成本。用“每个成功任务的总成本”复排，才是表格之后真正有用的第二轮排序。

这轮降价至少把一件事说得很明白：大模型服务已不再只有“最强模型”的单行报价。厂商正在把能力拆成不同的成本层。对应用方而言，比“哪个模型最强”更实际的问题是：我的工作流里，哪一步真的值得最贵的判断？
