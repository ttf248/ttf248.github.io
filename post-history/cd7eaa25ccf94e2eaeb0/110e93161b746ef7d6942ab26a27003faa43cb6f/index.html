这篇文章从一个月一个月的记录开始，而不是从模型排行榜开始。2022 年 11 月以后，AI 产业几乎每个月都在换一次问题：先是普通人能不能使用大模型，然后是模型能不能看、听、生成和推理，接着是能不能调用工具、操作电脑，最后才是这些能力能不能留下用户、进入预算并形成现金流。

时间线只选已经发生的高信号事件。模型发布、开放权重、产品公开可用、政策生效和公司治理可以进入；预告、传闻、尚未完成的融资和单日股价波动不单独凑数。每月最多 3 条，2026 年 7 月截至 7 月 13 日。

2022 年：入口被打开

11 月：ChatGPT 公开亮相

  • 11 月 30 日，OpenAI 发布 ChatGPT 研究预览。 对话框成为大模型第一次面向大众的产品入口，模型能力从研究机构的演示变成普通人可以反复使用的软件。OpenAI：Introducing ChatGPT

这个月的判断： 重要的不是 ChatGPT 是否第一个会生成文字，而是自然语言第一次成为足够低门槛的软件界面。

12 月：从演示走向扩散

  • ChatGPT 进入快速扩散期。 OpenAI 后续发布记录显示，用户开始围绕上下文、联网、插件和代码解释器提出产品需求，聊天产品不再只是一次性的问答演示。ChatGPT 发布记录

这个月的判断： 产业的第一个增量来自使用习惯，而不是新模型名称。用户先学会把任务交给模型，开发者才开始寻找可嵌入的工作流。

2023 年：能力、开放权重和资本开支同时加速

1 月：云与办公开始绑定

  • 微软宣布扩大与 OpenAI 的合作。 合作把模型能力、Azure 算力和办公软件放到同一条商业链上，AI 从独立产品开始进入云和生产力软件。Microsoft：延长与 OpenAI 的合作

这个月的判断： 闭源模型的优势从参数规模扩展到云、分发、企业合同和持续服务。

2 月：Bard 与 LLaMA 分叉

  • Google 公开介绍 Bard。 搜索公司开始正面回应 ChatGPT，生成式 AI 进入搜索入口竞争。Google：Bard 与搜索更新
  • Meta 发布 LLaMA 研究模型。 较小模型、公开研究和社区复现，给开放模型生态提供了重要起点。Meta：Introducing LLaMA

这个月的判断： 同一场竞争分成两条路：一条争夺稳定的云端入口，一条争夺开发者、权重和本地部署权。

3 月：GPT-4 开始连接工具

  • 3 月 14 日，GPT-4 面向 ChatGPT Plus 发布。 讨论重点从“能不能写”转向复杂指令、代码、推理和专业任务。OpenAI：GPT-4 research
  • 3 月 23 日，ChatGPT 开始提供插件实验。 浏览、代码解释器和第三方插件把模型从回答者推向工具调用者。ChatGPT 发布记录

这个月的判断： 模型能力的价值开始取决于能否接触最新信息、计算环境和外部服务。

4 月：Google DeepMind 合并

  • Google 合并 Google Brain 与 DeepMind，成立 Google DeepMind。 研究团队、算力和产品路线被放进同一个组织，Google 明确把下一代多模态模型作为核心方向。Google：成立 Google DeepMind

这个月的判断： 模型竞争不只是研究突破，也需要把人才、算力和产品分发组织起来。

5 月：长上下文遇上 GPU 订单

  • Anthropic 发布 100K 上下文窗口。 长文档、合同和代码仓库成为模型的输入，长上下文开始从研究指标变成企业产品卖点。Anthropic：100K Context Windows
  • 英伟达财报把 AI 预期变成 GPU 订单。 FY2024 第一季度数据中心业务和下一季度指引显著超出市场预期，市场开始沿着算力、网络和数据中心给 AI 定价。NVIDIA：FY2024 Q1 财报

这个月的判断： 上游基础设施可以先收到真实订单，应用层的收入、续费和利润则要晚很多；上下文越长，来源、权限和核验也越重要。

6 月：API 开始会调用函数

  • OpenAI 为 API 增加 function calling、长上下文和更低价格。 开发者可以让模型按 JSON Schema 输出函数参数，模型与外部工具的连接开始变得可编排。OpenAI：Function calling and other API updates

这个月的判断： 工具调用的关键不是模型会不会说“我可以帮你”，而是能否稳定地产生可执行、可校验的结构化结果。

7 月：开放权重与闭源模型并进

  • Meta 与微软发布 Llama 2。 模型权重、起始代码和商业使用条件被更广泛地开放，开发者可以在云端或本地构建自己的应用。Meta：Llama 2
  • Anthropic 发布 Claude 2。 更长输入、代码和推理能力让闭源模型竞争从聊天体验延伸到长文档和开发者 API。Anthropic：Claude 2

这个月的判断： “开源”开始成为产业口号，但真正影响部署的是许可证、权重、显存、推理速度和维护责任。

8 月：Code Llama 抢代码入口

  • Meta 发布 Code Llama。 开放模型开始专门争夺代码生成、补全和本地开发场景。Meta：Code Llama

这个月的判断： coding 之所以先形成付费边界，是因为代码任务有测试、提交和交付结果，价值比泛聊天更容易验收。

9 月：ChatGPT 进入多模态

  • OpenAI 把图像理解、语音和图片对话带入 ChatGPT。 文本模型开始成为多模态工作入口。OpenAI：ChatGPT 图像与语音更新

这个月的判断： 模型处理的对象从文字扩展到截图、会议记录和文件，但看懂材料不等于知道材料是真的。

10 月：图像生成进入对话

  • DALL·E 3 进入 ChatGPT Plus 和 Enterprise。 图片生成从独立提示词工具进入对话式修改流程，同时开始尝试用来源分类器识别生成内容。OpenAI：DALL·E 3

这个月的判断： AIGC 的竞争开始从一次生成转向迭代、版权、来源和可信度。

11 月：DevDay 与治理危机

  • OpenAI DevDay 发布 GPT-4 Turbo、Assistants API、视觉能力和更低价格。 API、检索、函数调用和助手框架把模型进一步嵌入应用。OpenAI：DevDay 新模型和开发者产品
  • OpenAI 董事会突然解雇并随后恢复 Sam Altman。 一周内的治理危机让模型公司治理、股东关系和人才依赖成为产业事实的一部分。OpenAI：Sam Altman 返回并组建新董事会

这个月的判断： 模型公司的产品风险之外，还有董事会、核心人才、资本和合作伙伴风险。

12 月：Gemini 把多模态带入产品

  • Google 发布 Gemini 1.0。 Gemini 从一开始就按 Ultra、Pro、Nano 分层，覆盖云端、应用和设备端，并强调原生多模态。Google：Introducing Gemini

这个月的判断： 模型竞争不再只有一个网页聊天入口，而是同时争夺搜索、手机、云和开发者工具。

2024 年：多模态、推理和 Agent 进入产品

1 月：GPT Store 尝试分发助手

  • OpenAI 上线 GPT Store。 用户可以发布和发现定制 GPT，模型平台开始尝试把提示词、知识库和工具组合成可分发的软件单元。OpenAI：Introducing the GPT Store

这个月的判断： 平台化的难点从“能不能做一个助手”转向发现、分发、权限和持续使用。

2 月：Sora 与长上下文竞赛

  • OpenAI 发布 Sora 研究预览。 文生视频把生成式模型的竞争带到时间一致性、物理世界模拟和视频来源验证。OpenAI：Sora
  • Google 发布 Gemini 1.5，强调长上下文和 MoE 架构。 模型开始处理更长的视频、代码库和多文档输入。Google：Gemini 1.5

这个月的判断： 多模态的下一道门槛不是生成一帧漂亮画面，而是维持长时间、长上下文里的连贯性。

3 月：模型开始按能力分层

  • Anthropic 发布 Claude 3 系列。 Opus、Sonnet、Haiku 用不同的能力、速度和成本覆盖企业 API，模型选择开始变成路由问题。Anthropic：Claude 3 family

这个月的判断： “最强模型”不再是唯一答案，延迟、价格和任务难度同样决定产品是否可用。

4 月：Llama 3 扩大开放生态

  • Meta 发布 Llama 3。 8B 和 70B 模型向社区开放，训练数据规模、工具链和云合作伙伴同步扩大。Meta：Llama 3

这个月的判断： 开放权重模型开始从研究替代品变成完整生态，部署方可以用成本和数据边界换取控制权。

5 月：GPT-4o 开启实时交互

  • OpenAI 发布 GPT-4o。 文本、视觉和音频能力被放进同一个更快的模型，实时语音交互成为产品重点。OpenAI：GPT-4o

这个月的判断： 多模态不再只是上传文件，实时交互开始争夺手机、客服和办公入口。

6 月：AI 进入设备与工作流

  • Apple 发布 Apple Intelligence。 设备端模型、个人上下文、Private Cloud Compute 和 ChatGPT 接入被放进 iPhone、iPad 和 Mac 的系统体验。Apple：Apple Intelligence
  • Anthropic 发布 Claude 3.5 Sonnet。 模型在代码、视觉和工具使用方面的改进，把 coding 和 Agent 任务推到闭源模型竞争中心。Anthropic：Claude 3.5 Sonnet

这个月的判断： AI 开始从“打开一个网站”进入设备和工作流，隐私、权限和延迟也变成体验的一部分。

7 月：大模型转向低成本路由

  • Meta 发布 Llama 3.1 405B。 开放权重模型开始直接对标前沿闭源模型，并提供长上下文和 Agent 参考系统。Meta：Llama 3.1
  • OpenAI 发布 GPT-4o mini。 更小、更便宜的模型推动简单任务本地化或批量化，模型路由的经济性更清楚。OpenAI：GPT-4o mini

这个月的判断： AI 产品的单位经济不只靠最强模型，低成本模型负责大量简单任务才有机会把调用变成长期预算。

8 月：AI Act 进入实施

  • 欧盟《人工智能法案》生效。 风险分级、透明度和通用人工智能模型义务开始进入正式实施阶段。EUR-Lex：Regulation (EU) 2024/1689

这个月的判断： 监管不再是发布前的抽象讨论，而会逐渐进入模型文档、部署流程和企业采购清单。

9 月：推理模型出现新曲线

  • OpenAI 发布 o1-preview 和 o1-mini。 推理模型把更多计算放到回答阶段，数学、代码和复杂任务开始按“思考多少”定价。OpenAI：o1-preview 和 o1-mini

这个月的判断： “更大”之外出现了“想得更久”这条能力曲线，等待、token 和复核成本需要一起计算。

10 月：Agent 开始操作电脑和搜索

  • Anthropic 发布计算机使用能力。 Claude 可以看屏幕、移动鼠标、点击和输入，Agent 从调用 API 走向操作通用软件。Anthropic：computer use
  • OpenAI 发布 ChatGPT Search。 聊天入口开始直接返回带链接的实时网络答案，搜索和问答的边界进一步变窄。OpenAI：ChatGPT search

这个月的判断： Agent 的价值来自执行，但执行能力越强，权限、提示词注入、错误回滚和责任边界越不能省略。

11 月：MCP 连接工具与数据

  • Anthropic 开放 Model Context Protocol。 MCP 试图用通用协议连接模型与外部工具、数据源，工具接入开始从单家公司实现走向生态协议。Anthropic：Model Context Protocol

这个月的判断： Agent 的瓶颈逐渐从模型本身转到工具协议、上下文管理和权限系统。

12 月：Sora 上线，Gemini 进入 Agent 时代

  • OpenAI 正式发布 Sora。 视频生成从研究预览进入订阅产品，并默认加入水印和来源识别措施。OpenAI：Sora is here
  • Google 发布 Gemini 2.0，强调 Agentic Era。 多模态输出、工具调用和实时交互成为下一代产品方向。Google：Gemini 2.0

这个月的判断： 2024 年的主线从“模型能生成什么”转向“模型能否在真实环境里完成一串动作”。

2025 年：推理成本下降，coding 变成 Agent 试验场

  • Google 发布 Gemini 2.5。 “思考模型”成为 Gemini 系列的核心叙事，长上下文和多模态推理继续向产品化推进。Google：Gemini 2.5

时间线之后，应该看什么

入口从聊天变成工作流

ChatGPT 先证明自然语言可以成为软件入口，GPT-4、插件、多模态和搜索再把入口连接到文件、网络和外部工具。2025 年以后，deep research、Claude Code、Codex 和各类终端 Agent 把任务链继续拉长。用户交付的已经不是一段回答，而是一份研究、一组修改、一套测试结果或一个可以继续运行的项目。

开放权重与闭源服务各自承担不同成本

路线 得到什么 付出什么 适合的问题
闭源 API 更新快、产品完整、企业支持和服务稳定性 调用费、配额、供应商依赖和数据边界 需要快速上线、复杂能力和统一交付
开放权重 可本地部署、可微调、数据边界更可控 显卡、内存、运维、许可证和升级成本 私有数据、本地试验和定制部署
混合路由 简单任务本地化，复杂任务调用云端 需要评估、路由、降级和监控 同时在意成本、隐私和能力的工作流

“开放”不等于免费，“闭源”也不等于没有生态。真正的部署判断要回到许可证、显存、上下文长度、推理速度、工具调用、故障处理和责任归属。

AIGC 从生成素材进入可信度竞争

文本要核实事实，图片要看来源和版权，视频要确认时间与素材，声音要考虑身份边界。生成成本下降以后，核验成本反而更重要。视觉完成度不能替代证据链，模型的自信语气也不能替代原始文件和可复现过程。

Coding 是最早能被验收的 Agent 场景

补全代码只是起点。真正的 coding Agent 需要读取仓库、理解约束、修改文件、执行命令、运行测试、处理失败、保留检查点，并让人可以审查和回滚。软件工程有清楚的交付边界，所以比泛聊天更容易形成订阅或企业预算；但这也意味着模型生成的每一行代码都要接受测试和维护。

AI 股票要从算力订单走到现金流

AI 股票不是一条同时上涨的直线。早期市场买的是入口和想象，2023 年开始买 GPU 订单和数据中心，2025 年以后则更关心单位推理成本、应用付费、资本开支和模型公司的融资能力。上游可以先收到钱，应用层还要经过试点、采购、续费和利润验证。

接下来更值得跟踪三张表：

  1. 云厂商的资本开支、订单和剩余合同负债，决定基础设施需求还能滚多久。
  2. 模型公司的收入、亏损、推理成本、客户集中度和现金流，决定能力是否能变成预算。
  3. coding 和 Agent 产品的使用深度、返工率、测试通过率和续费，决定“能完成任务”是否真的等于“有商业价值”。
