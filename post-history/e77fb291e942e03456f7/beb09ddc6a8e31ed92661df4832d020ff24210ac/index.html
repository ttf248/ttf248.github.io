더블 11 행사를 빌려 알리바이가 새 서버를 구매했습니다. 경제적인 버전으로, 연간 99위안이고, 사양은 높지 않지만 집에서 제공하는 서비스의 방화벽 역할을 하는 데도 괜찮습니다. 이 이벤트는 2026년까지 진행됩니다.

특이적으로 상하이 지역 서버를 선택했고, 낮은 지연 시간 프록시로 집의 컴퓨터를 연결했습니다. win11과 windows server 2022인데, 서버 버전은 나중에 배포되었고, 사용하려고 하니 갑자기 접근 거부 메시지를 받았습니다. 서버 업데이트 때문이라고 생각해서 잠시 기다리니 정상적으로 복구될 줄 알았는데, 5분 정도 지나서 다시 시도해도 여전히 로그인되지 않습니다. 관련 오류를 검색해 보니 누군가가 로그인을 시도하고 있고, 비밀번호가 너무 많이 틀렸기 때문에 현재는 로그인이 불가능하다고 합니다.

이전에도 보안 공격 스크립트를 접해본 경험이 있어서, 이러한 로그인 시도는 정상적인 행동이 아니라고 바로 생각했다. 누군가가 서비스를 공격하고 로그인 서버를 무작위로 해킹하려 하는 것 같았다. 서버 방화벽 설정이 간단하게 되어 있어 백리스트가 설정되어 있지 않았고, 두 대의 기계의 3389 포트를 프록시했기 때문에 공공 네트워크에 노출되었다. 마치 연못 속 미끼와 같은 상황이었다. 스크립트 키드가 공격하고 있다는 것을 알았으니, 다음 단계는 간단했다. 방화벽 백리스트를 설정하여 회사 IP 주소와 집 IP 주소만 프록시 서비스에 접속하도록 허용하면 된다.

frps 에이전트 서버는 이전에도 실행 로그를 설정하지 않았는데, 로그를 켜니 정말 좋네요. 전국 각지의 프록시 IP 주소들이 제 집의 서버에 접속을 시도하고 있었어요. 다행히 한 대는 서버 버전이라 문제점을 깨닫게 되었고, 그렇지 않으면 win11 그 컴퓨터는 결국 해킹당할 거예요. 비밀번호 설정이 꽤 간단했거든요.
