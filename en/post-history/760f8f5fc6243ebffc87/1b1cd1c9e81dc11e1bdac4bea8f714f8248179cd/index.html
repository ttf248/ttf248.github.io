This site is built with Hugo, but I’ve always used Chinese titles, which results in unfriendly URLs for the articles. To put it simply, they don’t look very good when shared; Chinese characters are encoded as %E4%BD%A0%E5%A5%BD and so on in the links. While this can be solved by setting slugs, it’s too much trouble to do manually each time.

So, today I tried using Claude4 to develop a translation assistant that automatically converts Chinese titles into English slugs and adds hyperlinks in articles. This can avoid manual setup.

Claude 4 is truly impressive; its ability to understand context has been significantly improved, and its efficiency in handling complex tasks has also increased dramatically

Code implementation

First, let me outline the implementation approach: we need to scan all articles, extract tag information and article titles, and then call a local large language model (such as gemma-3-12b-it) for translation

In practical development, Claude4 demonstrates several significant advantages compared to previous generations of large models. Due to the diverse functional requirements, Claude4 automatically designs an interactive menu, comprehensively considering various use cases. For example, in terms of tag processing, Claude4 not only supports tag statistics and analysis but also includes classification statistics and can even detect untagged articles. Furthermore, it provides preview and generate tag page functions.

Whether it’s connecting to local large models, adding new translation caches, or conducting large-scale code refactoring, Claude4 completed everything in one go with virtually no issues. Although the project is not large in scale, it includes many small features. In the past, large language models often forgot previous content during development, but Claude4 performed exceptionally well this time, with almost no instances of forgetting context.

In short, intelligence has improved, and we are preparing to switch to Claude4 for more development work as the primary model for daily coding

Translation cache

Speaking of this, apart from reducing the number of large model calls, running a 12b model locally is quite efficient and doesn’t cause delays. However, if you need to call the large model each time, it will still be a bit slow. Secondly, in order to keep the article links consistent, when performing a full update operation, long article titles can occasionally lead to different translation results, causing the article link to change – which is quite awkward.

Feature optimization

The entire project was thrown to Claude4, and it analyzed potential areas for optimization, resulting in the following suggestions:

配置外置化 - 提高可维护性和灵活性
结构化日志 - 便于问题排查和监控
性能监控 - 了解系统运行状况
用户体验 - 进度条等视觉反馈
错误处理 - 更完善的异常处理机制
代码组织 - 更清晰的模块划分

I reviewed the code, and everything is fine. For example, with configuration files, I know how to convert the original code’s configurations into default ones. When reading the configuration file, if a corresponding file doesn’t exist, it will automatically generate a default one, avoiding user errors.

Hugo tag automation management tool

A smart tag management tool designed specifically for Hugo blogs, supporting AI translation, local caching, and a user-friendly interface

Key Features

AI intelligent translation

  • Local AI model translation based on LM Studio
  • Chinese tags are automatically converted into SEO-friendly English slugs
  • Supports batch translation, improving processing efficiency

Intelligent Cache System

  • Local JSON cache to avoid repeated translations
  • Automatically detects cache status, saving API calls
  • Support for cache management and clearing functions

Friendly user interface

  • Intuitive command-line menu system
  • Colored output, clear and easy to read
  • Preview function, safe and reliable

Data analysis and statistics

  • Tag Usage Frequency Analysis
  • Categorized Statistics and Visualization
  • Untagged Article Detection

Get Started Quickly

Environmental requirements

  • Go 1.21+
  • LM Studio (Optional, for AI Translation)

Install and run 

# 克隆项目
git clone https://github.com/ttf248/hugo-slug-auto.git
cd hugo-slug-auto

# 安装依赖
go mod tidy

# 运行工具
go run main.go [content目录路径]

Basic Usage

  1. Tag Analysis: View blog tag usage statistics
  2. Generate tag pages: Create dedicated pages for each tag
  3. Article Slug Management: Generate SEO-friendly URLs for article titles
  4. Cache Management: View and manage translation cache
