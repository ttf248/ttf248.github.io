GPT-5.6の値下げ後、国内外の最新大規模モデルAPIは実際にはいくら価格差があるのか

只保留各厂最新公开 API 模型；OpenAI 完整列出 Sol、Terra、Luna

2026年07月31日
読了時間: 14分
GPT-5.6 Terra
v8.2.0
中文 English

前バージョンの問題は計算ではなく、サンプルの選定にありました。「代表的な SKU」を選んだ一方で、ユーザーが求めていたのは「各メーカーの最新モデル」でした。古い ERNIE 5.0、GLM-5、Kimi K2.6、MiniMax M2.7 を「最新価格」という表に載せると、その後のパーセンテージは比較可能性を失います。

今回は一つのルールだけを採用する。各社から、現時点で最新かつ API 経由で公開利用可能な自社開発のテキストモデルを一つだけ採用するというものである。OpenAI は、展開するものであり圧縮するものではない例外である。GPT-5.6 世代には Sol、Terra、Luna の 3 段階があり、3 つすべてが API で利用可能であるため、Terra だけで OpenAI 全体を代表するわけにはいかない。

まず、今回の「ChatGPTの値下げ」で実際に何が下がったのかを明確にしておく。OpenAIは7月30日にGPT-5.6 Terraの標準API価格を$2.50 / $15 から $2 / $12 に、Lunaを$1 / $6 から $0.20 / $1.20 に改定した。Solは据え置きである。ここで対象となっているのはAPIの従量課金価格であり、ChatGPT/Codexのサブスクリプション月額料金が割引されるわけではない。発表でも、サブスクリプション価格とプランの割当予算は据え置きであり、各プロダクトにおけるTerraとLunaのクレジット消費量が少なくなるだけだと明記されている。

最新モデルだけの価格表

合成価格 = キャッシュされていない入力トークン 100万件 + 出力トークン 100万件。Terraの $2 + $12 = $14 を 100% とする。人民元の表示価格は $1 = ¥6.7939 の固定レートで換算したものであり、並べ替えのみを目的としています。キャッシュ、Batch/Flex/Fast、ツール呼び出し、税金、法人契約価格は含まれていません。

表内の「最新」には、やや整然としていない2つの形態があります。Doubao-Seed-Evolving は同じモデル ID によるローリングアップデートで、通常のバージョン番号のような固定されたリリース日はありません。DeepSeek-V4-Pro は現在公開されている API フラッグシップのプレビューシリーズです。これらは、後続のモデルに置き換えられた歴史的な SKU を使用するよりも、この表の基準によりよく適合しています。

API は存在するが、価格のランキングには参加していない最新のモデル
ベンダー 最新の公開 API モデル なぜ割合を計算しないのか
Zhipu（智譜） GLM-5.2 公式に最新のフラッグシップであり API 対応と確認されているが、公開クロール可能な公式ページにトークン単位の価格が掲載されていないため、GLM-5.1 の旧価格をそのまま流用することはできない。
Cohere Command A+ trial および production key には使用量上限付きの無料枠があり、本番デプロイは Model Vault 経由となるため、主表と横並びで比較できるトークン単位の公式価格が存在しない。
Mistral Leanstral 1.5 無料 API エンドポイントが提供されているが、Lean 4 形式的検証専用となっており、汎用タスク向けの本番 API に対する $0 価格ではないため、この汎用タスクのコスト表には掲載できない。

これは漏れではなく、「最新のものだけを見る」と実際に直面する状況です。新製品の中には、最初に試用枠を提供するものもあれば、法人チャネル経由でのみ取引されるものもあり、公開資料にはトークンごとの価格ではなくモデルの説明だけが掲載されているものもあります。前世代の価格を使って表を埋めてしまうと、一見 complete に見えますが、実際的问题是「一時的に比較できない」から「誤った数値」に問題を書き換えてしまうことになります。

この価格改定は OpenAI 自社の3つの階層において何を意味するか

Sol の合成価は Terra の 2.5 倍（50% 高い）；Terra が中間に位置し；Luna は Terra の 10% です。したがって、今回の Terra と Luna の値下げは「フラッグシップモデル全体が安くなった」というわけではなく、OpenAI が中低コスト帯のモデル間の距離をさらに広げつつ、Sol の高価格帯を維持しているのです。

OpenAIが挙げた理由は推論効率の向上である。モデル、推論システム、そしてツールとコンテキストを接続するエージェント層がすべて最適化されていると説明している。発表によれば、本番カーネルの最適化によりエンドツーエンドのサービスコストが20％削減され、実験ではトークン生成効率が15％以上向上したとされる。これはベンダー側からの開示であり、値下げ余地が存在する理由を説明するものではあるが、外部監査に耐える完全なコスト表ではない。低廉な価格設定が主に大量のAPIワークロードの獲得を目指したものかどうかは、価格体系に対する分析に過ぎず、公式な動機として扱うことはできない。

この表は選定の代替にはならない

価格は高いものから安いものへと並べていますが、それはタスクが良いものから悪いものへと並んでいるということではありません。長いコンテキストは段階的な価格設定を引き起こし、キャッシュヒット、推論トークン、ツール呼び出し、再試行回数、地域および企業契約もすべて実際の請求額を変えます。表中の「1M 入力 + 1M 出力」は、購入前の統一的な選別基準に過ぎません。

実際に選ぶときは、10〜20個の実タスクでテストするほうが信頼できます。まず成功率、レイテンシ、人手によるやり直し率を確認し、それから入力、出力、推論トークン、キャッシュヒット、そして総コストを記録します。最後に比較すべきは「タスク1件あたりの成功コスト」であり、この表に並んでいる単独の単価ではありません。

執筆メモ

本文は 2026-07-31 の公開 API 価格表スナップショットであり、調達、投資、または製品選定のアドバイスを構成するものではない。検証済みのベンダーのみを含み、世界中のすべての API プロバイダーを網羅するものではない。モデルの能力、トークナイザー、コンテキスト、キャッシュ、推論トークン、ツール課金、地域、法人契約などによって異なるため、表内のパーセンテージは同等の性能や実際のタスクコストのランキングとみなすことはできない。

元のプロンプト

ChatGPT シリーズのモデルが価格改定を発表しました。関連情報を整理し、なぜ値下げするのか？各社の大規模モデルメーカーの API 価格（国内・国外）をまとめ、表に整理します。ChatGPT 5.6 terra を基準として、各社の価格比較のパーセンテージを計算し、高いものから安いものへと並べ替えます。

整理された表の情報は完全ではありません。ChatGPT 自社の他のモデルが列举されておらず、各社の大手メーカーのモデルも最新リリースのものではありません。必要なのは各社の最新モデルの価格だけです。
