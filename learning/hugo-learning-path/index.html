Hugo 学习区：内容与模板入门

用三章建立一套可维护的内容目录、阅读路径和发布边界。

更新状态
持续更新
章节数量
3 个章节
从第一章开始 →

这不是一份 Hugo API 手册，而是一条从写一篇 Markdown 开始，走到把一组内容维护成学习资料的短路径。

三章分别处理内容结构、阅读模板和发布检查。读完后，你应该能判断：一份新内容应当是一篇博客，还是一个可以持续长大的学习集合。

本部分内容

  1. 章节先把内容当成一棵树目录负责归属，weight 负责顺序；日期不再决定读者从哪里开始。
  2. 章节用模板把章节连成阅读路径章节树、面包屑和前后导航，让一组页面不再只是同标签的文章。
  3. 章节把构建当成发布前的边界检查内容独立不只在页面上，也要体现在首页、搜索、订阅和验证里。
