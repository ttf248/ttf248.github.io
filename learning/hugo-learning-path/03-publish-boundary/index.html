把构建当成发布前的边界检查

内容独立不只在页面上，也要体现在首页、搜索、订阅和验证里。

所属集合

最后更新
2026年08月11日

如果课程章节仍然出现在博客首页、年度归档和日常订阅里，它在读者眼中还是博客的一部分。真正的独立需要把“哪里能发现它”也设计清楚。

本站把 post、notes 保留为博客流的主内容；学习区不加入 mainSections。因此，首页的最近更新、归档和博客搜索不会自动吸入课程章节。学习区自己的根页则生成独立搜索索引，只搜索课程中的叶子章节。

首页仍然可以给学习内容一个轻量入口：展示集合卡片，而不是展示某一章。卡片只说这门课叫什么、处于什么状态、已经有几章，点击后进入课程首页。这样首页保留了“我正在长期整理什么”的信息，又不会把一节技术课伪装成当天发布的博客文章。

最后一步是构建。模板和样式的错误往往不会出现在 Markdown 文件里，而会在 Hugo 渲染时暴露。修改学习区后至少运行：

python -m unittest tests.test_learning_section
hugo --renderToMemory --panicOnWarning

前者保护内容边界和模板契约，后者编译实际页面、SCSS、脚本和输出格式。只有两者都通过，新的章节才算真正进入站点。
